How to Use This Visualization

⚠ This tool is a work in progress. Course data, prerequisite logic, and graduation requirements may not perfectly reflect the official Davidson College catalog. Always verify with your advisor or the official registrar.

Navigating the Graph

  • Pinch or scroll wheel — zoom in and out
  • Click and drag — pan around the graph
  • Reset Zoom button — return to the original view

Node Colors

  • Blue — course is available to take
  • Green — course marked as taken
  • Gray — prerequisites not yet satisfied

Interacting with Courses

  • Hover over a node to see its name, prerequisites, and a short description
  • Single click a node or check its sidebar checkbox to mark it as taken
  • Double click a node to read its full course description
  • You can only mark a course as taken if its prerequisites are satisfied — missing prerequisites will be highlighted in red

Sidebar

  • Check courses you have completed to track your progress
  • Progress indicators show how many requirements you have fulfilled in each section

Edges

  • Solid arrow — represents a required prerequisite path to a course
  • Dashed arrow — represents an optional prerequisite path to a course (i.e., not the only path)
